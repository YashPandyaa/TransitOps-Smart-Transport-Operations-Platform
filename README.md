# TransitOps

Transport Operations Platform (hackathon starter)

## Prerequisites
- Node.js 18+
- PostgreSQL

## Setup
1. Create DB + user.
2. Copy backend env:
   - `cp backend/.env.example backend/.env`
3. Install deps:
   - `npm install`
   - `npm install --prefix backend`
   - `npm install --prefix frontend`

## Run
- Dev (backend + frontend):
  - `npm run dev`

Backend will run at `http://localhost:3001` (default), frontend at `http://localhost:5173`.
